# Dashboard Financeiro 📊

Um dashboard financeiro desenvolvido para facilitar o gerenciamento e a visualização de receitas, despesas e saldo pessoal.

O projeto foi desenvolvido com HTML, CSS e JavaScript, com foco em organização de dados, manipulação do DOM e armazenamento local.

## ⚙️ Funcionalidades

- Visualização do total de receitas, despesas e saldo;
- Filtragem de movimentações por períodos de 30 dias até 1 ano;
- Visualização de dados por meio de gráficos;
- Adição de novas receitas e despesas;
- Filtros nas tabelas de movimentações;
- Alternância entre tema claro e escuro;
- Armazenamento de dados no LocalStorage;
- Exportação de dados em formato CSV.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js

## 📚 Aprendizados e desafios

Durante o desenvolvimento deste projeto, pude aprofundar meus conhecimentos em JavaScript, principalmente na manipulação do DOM, armazenamento de dados com LocalStorage e organização do código em módulos.

Alguns dos principais pontos técnicos que trabalhei foram:

- **Estruturação de dados:** utilização de objetos para armazenar as informações de cada receita ou despesa, incluindo data, valor, local e tipo da movimentação.
- **Manipulação de gráficos:** utilização do método `update()` do Chart.js para atualizar os gráficos conforme os dados são modificados.
- **Manipulação de dados:** implementação de filtros para facilitar a visualização das movimentações financeiras nas tabelas.
- **Modularização:** organização do JavaScript em módulos e funções com responsabilidades específicas, buscando manter cada função enxuta e evitar o excesso de código concentrado em um único lugar.

Além dos aspectos técnicos, aprendi que sempre posso aprender mais e que devo persistir para alcançar meus objetivos. Também percebi como boas decisões durante a etapa inicial do design fazem diferença na implementação e na responsividade do projeto.
